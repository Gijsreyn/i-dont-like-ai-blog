<h2 id="course-content">Course content</h2><p>This course takes you from Bicep Local Deploy fundamentals to publishing custom extensions that are production-ready. The getting started module starts with an introduction to the Bicep Local Deploy framework and its architecture. It covers how custom extensions work within Bicep's ecosystem. You'll set up your development environment and verify your installation using a quick-start project.</p><p>Next, you'll be building your first complete extension, expanding on the quick-start project. From looking at the project structure to defining type models with attributes, and lastly, implementing handlers that manage the resource lifecycle. </p><p>The advanced module lessons dive deeper into testing and documentation. You'll be using the <code>bicep-local-docgen</code> CLI tool to validate your documentation.</p><h2 id="prerequisites">Prerequisites</h2><p>Before starting this course, you should have:</p><ul><li><strong>C# programming</strong>: Be familiar with C# syntax, classes, and properties.</li><li><strong>PowerShell basics</strong>: Understand PowerShell commands and scripting for running build scripts and tests.</li><li><strong>REST APIs</strong>: Basic understanding of HTTP methods (GET, POST, PUT, DELETE) and JSON.</li><li><strong>Command-line tools</strong>: Be comfortable running CLI utilities.</li></ul><p>Don't worry if you're missing some recommended knowledge. The course provides explanations along the way. The required knowledge is mainly for following the code examples and completing the exercises.</p><h2 id="what-youll-learn">What you'll learn</h2><ul><li><strong>Understand Bicep Local Deploy architecture:</strong> Learn what custom extensions are, how they extend Bicep's capabilities, and the role of Azure.Bicep.Local.Extension framework and documentation attributes.</li><li><strong>Build complete custom extensions:</strong> Create type models with documentation attributes, implement resource handlers, and test with Bicep files and Pester.</li><li><strong>Generate and publish documentation:</strong> Use <code>bicep-local-docgen</code> CLI to generate markdown documentation and validation.</li></ul><p>By the end of this course, you'll have a production-ready Bicep Local Deploy extension, including:</p><ul><li>Documentation</li><li>End-to-end tests</li><li>Publishing workflow</li></ul><p>You'll understand the complete lifecycle from initial concept to a published extension that users can consume in their Bicep templates.</p>
