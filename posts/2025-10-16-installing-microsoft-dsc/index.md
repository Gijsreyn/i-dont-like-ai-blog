<p>Before you get started, you need the actual CLI to work with. For that, you need to install DSC on your machine. In the following sections, you can find instructions on how to install it on <strong>Windows</strong>,<strong> Linux</strong>, or <strong>macOS</strong>.</p><h2 id="installing-dsc-for-windows-manually-from-github">Installing DSC for Windows manually from GitHub</h2><p>To install DSC for Windows from GitHub, follow these steps:</p><h3 id="step-1determine-your-os-architecture">Step 1 - Determine your OS architecture</h3><p>There are multiple methods for determining the operating system (OS) architecture. The following three examples demonstrate the use of the command prompt, PowerShell, or msinfo.</p><ol><li>Open a command prompt and type:&nbsp;<code>echo %PROCESSOR_ARCHITECTURE%</code>.</li><li>Open a PowerShell terminal session and type:&nbsp;<code>[System.Runtime.InteropServices.RuntimeInformation]::OSArchitecture</code>.</li><li>In your Quick Start menu, type in&nbsp;<code>msinfo32.exe</code>&nbsp;and locate the&nbsp;<code>System Type</code>&nbsp;property in the System Summary.</li></ol><h3 id="step-2download-the-asset">Step 2 - Download the asset</h3><p>After determining your OS architecture, proceed to download the release asset from GitHub.</p><ol><li>Open the following&nbsp;<a href="https://github.com/PowerShell/DSC/releases/" rel="noopener">link</a>&nbsp;in your favorite browser.</li><li>Select the version you want to download and scroll down.</li><li>Expand the&nbsp;<em>Assets</em>&nbsp;and press the asset relevant to your OS architecture.</li></ol><figure class="kg-card kg-image-card kg-card-hascaption"><img src="https://storage.ghost.io/c/dd/64/dd64ba9d-7bdd-441e-bb5f-13f8be709814/content/images/2025/10/image-7.png" class="kg-image" alt="" loading="lazy" width="1194" height="382" srcset="https://storage.ghost.io/c/dd/64/dd64ba9d-7bdd-441e-bb5f-13f8be709814/content/images/size/w600/2025/10/image-7.png 600w, https://storage.ghost.io/c/dd/64/dd64ba9d-7bdd-441e-bb5f-13f8be709814/content/images/size/w1000/2025/10/image-7.png 1000w, https://storage.ghost.io/c/dd/64/dd64ba9d-7bdd-441e-bb5f-13f8be709814/content/images/2025/10/image-7.png 1194w" sizes="(min-width: 720px) 720px"><figcaption><span style="white-space: pre-wrap;">Figure 1: DSC release assets</span></figcaption></figure><ol start="4"><li>Save the file to your&nbsp;<em>Downloads</em>&nbsp;folder.</li></ol><h3 id="step-3expand-the-archive-and-add-to-path">Step 3 - Expand the archive and add to PATH</h3><p>When the download is finished, you can expand the files to extract them to your application data folder.</p><ol><li>Right-click the file and select&nbsp;<em>Extract All…</em></li><li>Extract the files to&nbsp;<code>C:\Users\&lt;userProfile&gt;\AppData\Local\dsc</code>&nbsp;by replacing the&nbsp;<code>&lt;userProfile&gt;</code>&nbsp;with your profile name.</li><li>Open a command prompt and type:&nbsp;<code>rundll32.exe sysdm.cpl,EditEnvironmentVariables</code>&nbsp;to open the environment variables.</li><li>In your user variables, edit your&nbsp;<code>PATH</code>&nbsp;environment variable and include the path&nbsp;<code>C:\Users\&lt;userProfile&gt;\AppData\Local\dsc</code>.</li></ol><h3 id="step-4verify-the-installation">Step 4 - Verify the installation</h3><ol><li>Open a command prompt or PowerShell terminal session.</li><li>Type&nbsp;<code>dsc --version</code>:</li></ol><pre><code class="language-bash">dsc --version</code></pre><p>This should return the DSC version installed.</p><div class="kg-card kg-callout-card kg-callout-card-blue"><div class="kg-callout-emoji">ℹ️</div><div class="kg-callout-text">After the files are extracted, ensure that they are unblocked in your file system.</div></div><p></p><h2 id="installing-dsc-for-windows-using-powershell">Installing DSC for Windows using PowerShell</h2><p>To install DSC for Windows using PowerShell, you can run the following commands in a PowerShell terminal session.</p><h3 id="option-1using-psdsc-module">Option 1 - Using PSDSC module</h3><p>To install DSC using the PSDSC module, follow the steps below:</p><ol><li>Open a PowerShell terminal session.</li><li>Install the&nbsp;<code>PSDSC</code>&nbsp;module by typing:&nbsp;<code>Install-PSResource -Name PSDSC</code></li><li>Execute <code>Install-DscExe</code> in the same terminal session</li></ol><div class="kg-card kg-callout-card kg-callout-card-blue"><div class="kg-callout-emoji">⚠️</div><div class="kg-callout-text">Don’t confuse the&nbsp;<code spellcheck="false" style="white-space: pre-wrap;">PSDSC</code>&nbsp;module for the&nbsp;<code spellcheck="false" style="white-space: pre-wrap;">PSDesiredStateConfiguration</code>.</div></div><p></p><h3 id="option-2use-powershell-script">Option 2 - Use PowerShell script</h3><p>To install DSC using a PowerShell script, open a PowerShell terminal session and copy and paste the following:</p><pre><code class="language-powershell"># Define the GitHub repository and the asset pattern to download
$repo = "PowerShell/DSC"
$assetPattern = "dsc-win-.*.zip"&#10;
# Get the latest release information from GitHub API
$release = Invoke-RestMethod -Uri "https://api.github.com/repos/$repo/releases/latest"&#10;
$assetPattern = if ($env:PROCESSOR_ARCHITECTURE -eq 'ARM64')
{
  'DSC-*-aarch64-pc-windows-msvc.zip'
}
else
{
  'DSC-*-x86_64-pc-windows-msvc.zip'
}&#10;
# Find the asset that matches the pattern
$asset = $release.assets | Where-Object { $_.name -like $assetPattern }&#10;
if ($asset)
{
  # Download the asset
  $assetUrl = $asset.browser_download_url
  $downloadPath = Join-Path -Path $env:TEMP -ChildPath $asset.name
  Invoke-RestMethod -Uri $assetUrl -OutFile $downloadPath&#10;
  # Define the extraction path
  $extractPath = Join-Path -Path $env:LOCALAPPDATA -ChildPath 'dsc'&#10;
  # Create the extraction directory if it doesn't exist
  if (-not (Test-Path -Path $extractPath)) {
    New-Item -ItemType Directory -Path $extractPath
  }&#10;
  # Extract the downloaded zip file
  if (Get-Command -Name 'Expand-Archive')
  {
    Expand-Archive -Path $downloadPath -DestinationPath $extractPath -Force
  }
  else 
  {
    Add-Type -AssemblyName System.IO.Compression.FileSystem
    [System.IO.Compression.ZipFile]::ExtractToDirectory($downloadPath, $extractPath)
  }&#10;
  # Clean up the downloaded zip file
  Remove-Item -Path $downloadPath -ErrorAction SilentlyContinue&#10;
  # Unblock all files
  Get-ChildItem -Path $extractPath -Recurse | Unblock-File&#10;
  # Add to PATH
  $env:PATH += ";$extractPath"&#10;
  # Verify the installation
  dsc --version
}</code></pre><p></p><h2 id="installing-dsc-on-linux">Installing DSC on Linux</h2><p>To install DSC on Linux, follow these steps:</p><h3 id="step-1download-the-asset">Step 1 - Download the asset&nbsp;</h3><ol><li>Open a terminal session.</li><li>Determine your OS architecture by typing:</li></ol><pre><code class="language-bash">uname -m</code></pre><ol start="3"><li>Download the DSC release asset using&nbsp;<code>wget</code>. Replace&nbsp;<code>&lt;version&gt;</code>&nbsp;with the desired version number and&nbsp;<code>&lt;architecture&gt;</code>&nbsp;with your OS architecture (e.g.,&nbsp;<code>x86_64</code>):</li></ol><pre><code class="language-bash">wget https://github.com/PowerShell/DSC/releases/download/v&lt;version&gt;/DSC-&lt;version&gt;-&lt;architecture&gt;-linux.tar.gz</code></pre><h3 id="step-2extract-the-archive">Step 2 - Extract the archive&nbsp;</h3><ol><li>Create a directory to extract the files:</li></ol><pre><code class="language-bash">mkdir dsc</code></pre><ol start="2"><li>Extract the downloaded tar.gz file to the created directory:</li></ol><pre><code class="language-bash">tar -xvzf DSC-&lt;version&gt;-&lt;architecture&gt;-linux.tar.gz -C dsc</code></pre><h3 id="step-3move-files-to-the-appropriate-location">Step 3 - Move files to the appropriate location&nbsp;</h3><ol><li>Move the extracted files to&nbsp;<code>/usr/local/bin/</code>:</li></ol><pre><code class="language-bash">sudo mv dsc/* /usr/local/bin/</code></pre><h3 id="step-4update-path-environment-variable-in-bashrc">Step 4 - Update PATH environment variable in .bashrc&nbsp;</h3><ol><li>Add the DSC path to your&nbsp;<code>~/.bashrc</code>&nbsp;file:</li></ol><pre><code class="language-bash">echo 'export PATH=$PATH:/usr/local/bin/dsc' &gt;&gt; ~/.bashrc</code></pre><ol start="2"><li>Optionally, reload the&nbsp;<code>~/.bashrc</code>&nbsp;file to apply the changes:</li></ol><pre><code class="language-bash">source ~/.bashrc</code></pre><h3 id="step-5verify-the-installation">Step 5 - Verify the installation&nbsp;</h3><ol><li>Open a terminal session.</li><li>Type&nbsp;<code>dsc --version</code>&nbsp;to verify the installation:</li></ol><pre><code class="language-bash">dsc --version</code></pre><p>This should return the DSC version installed.</p><div class="kg-card kg-callout-card kg-callout-card-blue"><div class="kg-callout-emoji">ℹ️</div><div class="kg-callout-text">These steps have been tested on Ubuntu 22.04.</div></div><p></p><h2 id="installing-dsc-on-macos">Installing DSC on MacOS</h2><p>To install DSC on MacOS, follow these steps:</p><h3 id="step-1download-the-asset-1">Step 1 - Download the asset&nbsp;</h3><ol><li>Open a terminal session.</li><li>Download the DSC release asset using&nbsp;<code>curl</code>. Replace&nbsp;<code>&lt;version&gt;</code>&nbsp;with the desired version number and&nbsp;<code>&lt;architecture&gt;</code>&nbsp;with your OS architecture (e.g.,&nbsp;<code>x86_64</code>):</li></ol><pre><code class="language-bash">curl -L https://github.com/PowerShell/DSC/releases/download/v&lt;version&gt;/DSC-&lt;version&gt;-&lt;architecture&gt;-apple-darwin.tar.gz -o DSC-&lt;version&gt;-&lt;architecture&gt;-apple-darwin.tar.gz</code></pre><h3 id="step-2extract-the-archive-1">Step 2 - Extract the archive&nbsp;</h3><ol><li>Create a directory to extract the files:</li></ol><pre><code class="language-bash">mkdir dsc</code></pre><ol start="2"><li>Extract the downloaded tar.gz file to the created directory:</li></ol><pre><code class="language-bash">tar -xvzf DSC-&lt;version&gt;-&lt;architecture&gt;-apple-darwin.tar.gz -C dsc</code></pre><h3 id="step-3move-files-to-the-appropriate-location-1">Step 3 - Move files to the appropriate location&nbsp;</h3><ol><li>Move the extracted files to&nbsp;<code>/usr/local/bin/</code>:</li></ol><pre><code class="language-bash">sudo mv dsc/* /usr/local/bin/</code></pre><h3 id="step-4update-path-environment-variable-in-zshrc">Step 4 - Update PATH environment variable in .zshrc</h3><ol><li>Add the DSC path to your&nbsp;<code>~/.zshrc</code>&nbsp;file:</li></ol><pre><code class="language-bash">echo 'export PATH=$PATH:/usr/local/bin' &gt;&gt; ~/.zshrc</code></pre><ol start="2"><li>Optionally, reload the&nbsp;<code>~/.zshrc</code>&nbsp;file to apply the changes:</li></ol><pre><code class="language-bash">source ~/.zshrc</code></pre><h3 id="step-5verify-the-installation-1">Step 5 - Verify the installation</h3><ol><li>Open a terminal session.</li><li>Type&nbsp;<code>dsc --version</code>&nbsp;to verify the installation:</li></ol><pre><code class="language-bash">dsc --version</code></pre><p>This should return the DSC version installed.</p><div class="kg-card kg-callout-card kg-callout-card-blue"><div class="kg-callout-emoji">ℹ️</div><div class="kg-callout-text">These steps have been tested on MacOS 15 Sequoia.</div></div><p></p><h2 id="next-up">Next up</h2><p>You have now successfully installed DSC on your machine.
